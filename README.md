# Agentic RAG Policy Assistant

An Agentic Retrieval-Augmented Generation (RAG) system built with LangGraph, Groq LLM inference, and local Sentence Transformers.

## Features
- **Local Semantic Retrieval:** Embeds and searches policy documents using local vector embeddings.
- **Dynamic Tool Calling:** LangGraph ReAct agent calls policy retrieval and arithmetic operations based on user intent.
- **Inference Engine:** Groq API (`openai/gpt-oss-20b`).
